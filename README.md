
## TASKLY - YOUR DAILY TASK TRACKER
Taskly is a single-line command interface that can be used in a terminal to track and mark all your daily task. It allows the user to create, update, mark and delete any task.

## PREREQUISITES
- Python3++
- Linux terminal (tested in linux only)

## HOW TO INSTALL
Copy this repo into your system by using git clone
```shell 
git clone https://github.com/H-Abdullah/Taskly.git
```

## HOW TO USE
In order to use the script, follow the steps below:
1. Open a terminal then type:
```shell
cd Taskly
```
2. You will find taskly.py inside the directory then you can use it by using below example:
```shell
python3 ./taskly.py --help
```
## FEATURES
You can do:
- [x] Add new task
- [x] Update task with new description
- [x] Mark task with done or in-progress
- [x] Delete task using id
- [x] Clear all task
